Hermes Gmail

Hermes Gmail is a personal-use notification integration for the Hermes automation environment. It uses Google OAuth authorization to send notification emails through the account authorized by its operator.

The integration is intended for the operator's own monitoring workflows, including operational and security alerts. It is not a public email service and does not offer user registration.

Google account access is requested only with the permissions presented during OAuth consent. The Gmail send permission is used to send notifications; it does not itself grant permission to read the Gmail inbox.
